# 墨默三阶段战斗框架（hotfix5，开发验证版）

## 已接入
- 内核权威血量驱动、只前进的三阶段：75%/50%阈值，阶段与待转场标志存NBT。
- 攻击属性10/15/35；Boss射出的星陨箭按目标最大生命4%/8%/15%真伤。
- 一阶段空手绕8格、随机贴近及低概率持弓；二阶段起10格内恒正秩器、外侧星陨悲叹；武器由骨骼物品层显示。
- 二阶段普通近战命中调用内核合法回血0.5%；飞行撞击不走回血入口。
- 二阶段投射物概率闪避；三阶段普通受伤尝试闪避；成功后近距离反击击飞并FULL禁锢30tick。
- 三阶段高伤硬直抑制，领域施法例外；分身护盾复用原实现。
- 第一段转场强制排队死生领域；领域生成3只原版鱿鱼占位，域内追撞、推离、结束清理。
- 第二段转场爆炸声/粒子、绕场一圈、五轮前摇冲撞；冲撞加AeonianWeaken.PER_HIT（30tick）。
- 三阶段远距交替空中绕行与落地窗口，飞行目标速度3.6m/s。
- 真死后保留200tick，半径16球形范围亡语污染，每秒暂加40tick，仆从排除，结束移除。
- 仆从伤害事件取消；箭矢真伤与和弦额外过滤仆从。

## 尚属框架/待调整，不宣称已完全复现设计
- 步行属性以m/s除20暂映射，非精确地面实速；需要实机校准。奔跑专用动画未新增。
- 三阶段分身仍沿用50%触发一次，并非绑定每次和弦重召；用户未确认重召次数。
- 转场爆炸目前仅声画，不造成范围爆炸伤害、不破坏方块（伤害未指定）。
- 一阶段随机权重与冷却、闪避概率、飞行高度/持续窗口、污染增量均为具名临时参数。
- 死亡动画保持原美术，10秒保留与掉落时序待实机核验；暂不保存中途死亡进度。
- 鱿鱼是临时原版实体，手动域内移动，非最终独立章鱼实体；区块卸载中断的清理需后续加强。
- 手持物偏移需实机对齐；不改用户模型、贴图、动画。
