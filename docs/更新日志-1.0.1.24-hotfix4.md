# Tinker's Newlife 1.0.1.24-hotfix4 更新日志

本版是 **1.0.1.24 的第四个热修复**（上一版为 `1.0.1.24-hotfix3`）。
以**修复**为主，没有新增世界内容。

---

## 一、铁魔法联动

### 1. 特性之间「互相覆盖」—— 修复
- **超位魔法 × 奥术始源**：以前取两者最大值（只生效一个）⇒ 现在**相加**。
- **魔导 / 炽热 / 冷酷**：以前只算"最高单件" ⇒ 现在**按件叠加**（含 Curios 饰品）。
- **同一件物品上多个特性都要塞法术**：以前"已有容器就跳过"⇒ 现在往里**追加**（去重 + 容量检查）。
- 补上**饰品槽**扫描：魔导 / 炽热 / 冷酷 / 万法归一 / 奥法支配 / 刻印。

### 2. 奥法支配（魔金）按件叠加
- 以前不管穿几件，永远只加一次 100% ⇒ 现在**每件 +100%**（三件 +300%、四件 +400%）；
- 语言与手册文案同步写明"按件叠加"。

## 二、真伤与血量内核

### 3. 真伤在 1.20.1 根本改不动血 —— 修复（重大）
- 原因：1.20.1 **没有 `health` 字段**（血量存在同步数据里），旧代码把 `f_20920_`（其实是攻击动画）
  当成血量写；而且"抑制同步"标记泄漏后连 `setHealth` 也被跳过 ⇒ **真伤完全不掉血**。
- 现在：直接写 `DATA_HEALTH_ID`，拿不到字段时正确回落 `setHealth`，抑制标记用 `try/finally` 复位。

### 4. 试验假人：两段伤害 / 红字 / 血量被打空 —— 修复
- 直写同步数据不经过 `setHealth` 覆写 ⇒ 假人不再记第二段伤害；
- 同步它的 `lastHealth` 缓存 ⇒ 不再弹"真伤"红字；
- 会"自己记账"的目标（覆写 `setHealth`）⇒ `hurt` 收下后**不再重复改血** ⇒ 无限血量假人不会被打死。

### 5. 移除两处旧的"针对"逻辑
- 亚波伦额外血量通道（早已关闭）；
- 诡厄使徒低血处决兜底。
- 真伤现在只剩一条**通用链路**。

### 6. 血量内核加强（不针对任何模组）
- 内核不再信任 `getHealth()`，改读**同步数据本体**；
- 任何来源的 `setHealth` 掉血都要吃同一套「**每 tick 6% 上限 + 1.5 秒无敌窗**」；
- 负数 / NaN / ∞ 一律净化；死亡分支不再用 `kill()`（会被自家闸门挡下 ⇒ 0 血也死不掉）。

### 7. 墨默血条异常 / 打不死 —— 修复（**实机确认有效**）
- 有的模组在 `getHealth` 外套 `min(真血, 最大生命 + 自定义值)`，把显示血拖成负数；
- 现在每 tick 检测并清零该值，并把镜像血量**强制与权威值一致**（全服 tick 末尾最后一次写入）。

## 三、冰火联动

### 8. 龙血瓶与匠魂储罐 / 排液口交互无反应 —— 修复
- 原因：另一个联动模组也提供了同名物品的流体转换配方，但它引用的是**空标签**
  ⇒ 抢先匹配后解析成 0 mB ⇒ 表现为"右击完全没反应"。
- 现在：把 `forge:molten_{fire,ice,lightning}_dragon_blood` 填上我们三种**静止**龙血
  ⇒ 对方配方直接可用；我们自己的转换配方保留作为兜底。
