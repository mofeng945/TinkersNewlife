# 匠魂新生 1.0.1.28 · 墨默战斗与手册更新

Minecraft 1.20.1 / Forge。以下为相对 1.0.1.27 的变化。

## 墨默本体战

- 二阶段切换为商人墨默的配色；三阶段彩光从身体轮廓展开，随后背后浮现分层、反向旋转的双六芒星。
- 行走与奔跑改用不同姿势。持弓时，上半身拉弓、瞄准、松弦，下半身可以独立横移或后撤。补齐空手与持械近战、星梦一觉、阶段觉醒、空中冲撞、召影及死亡动作；修复大幅前倾时腰腿分离。
- 游射时身体朝向敌人，不再朝侧移方向瞄准。空中冲撞在前摇期间瞄准，出手后保持锁定的冲撞方向。
- 亡语不再给死亡动画额外叠加 90° 侧翻。紫色结界和地面六芒星标出 16 格影响范围，10 秒后随死亡爆炸消失；污染、爆炸与奖励的结算时机不变。

## 善恶与好感减伤

- Boss 墨默本体对玩家的伤害会根据玩家的善恶值和商人墨默的实际好感度减免。两项各取 0～50，每点减伤 0.6 个百分点，每项最多 30%，合计最多 **60%**。负值不倒扣；例如善恶 +20、好感 +50 时，减伤 42%。
- 此规则替代「心」对该次伤害的通用善恶乘算，不重复叠加。关闭「心」后仍保留好感部分。适用于本体的攻击、技能和星陨箭，不适用于分身或无归属的污染爆发，也不会缩短控制时间。

## 星井祭坛与帕秋莉手册

- 祭坛大柱移至门道两侧，地宫下行梯改到侧廊，修平南侧长阶与平台的接缝。新版入口用于新生成或重新放置的祭坛，不会翻修旧建筑。
- 中英文手册新增「眠觉教堂」「星井祭坛」「墨默：本体战」，介绍定位、召唤、宝库、阶段与减伤。修订「心」「咒力亲和」「拉莱耶的呼唤」，以现行的分难度规则替换旧善恶行为清单。
