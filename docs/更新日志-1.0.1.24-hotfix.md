# Tinker's Newlife 1.0.1.24-hotfix 修复日志

本版是 **1.0.1.24 的热修复**，内容变化只有一条：**日志刷屏**。

---

## 修复

### 日志被 `Tool stack constructed using non-modifiable tool` 刷屏（Render thread，约 120 条/秒）
- **现象**：打开「构筑 / 拟造蓝图」的物品选择界面时，日志以约 **120 条/秒** 的速度刷这条警告；
  平时造工筷子子弹、用矿工透镜时也会零星出现。
- **原因**：这条警告由 **TConstruct** 打印（`ToolStack` 发现传入的匠魂工具**没有 NBT** 时会提示）。
  刷屏的调用方是本模组的界面：`ConstructSelectScreen` **每帧都 `new ItemStack(匠魂工具)` 去画图标**，
  格子里正好有 2 件匠魂工具 ⇒ 每帧 2 条，正好约 120 条/秒。
- **修复**：
  - 构筑选择界面：匠魂物品的显示用栈改为**初始化一次并缓存**
    （`ToolStack.createTool(..., MaterialNBT.EMPTY)` + `updateStack`），渲染与 tooltip 复用；
  - 工筷子子弹：匠魂弹药物品改用 `createTool` 正规初始化，不再对空栈调用 `ToolStack.from`；
  - 拟造物质化（`materializeTCon` / `materialsOf`）与矿工透镜：先判断 `ToolStack.isInitialized`，
    空栈直接按“无材料 / 无该词条”处理（行为不变，只是不再触发警告）。
- **玩家侧**：装本版即可，**不需要**改 TConstruct 配置。
  想彻底静音也可以在 `config/tconstruct-common.toml` 把 `logInvalidToolStack` 设为 `IGNORE`（默认 `WARNING`）。
