## 一、总览（可以直接拿去当开头段落 ✓）

「善恶系统」记录你在世界里的每一次选择：**做好事加分、做恶事扣分**，分值直接改变你的角色强度与世界的对待方式。

| 项 | 说明 |
|---|---|
| **分值单位** | **1 点 ＝ 1%** ✓（不设"点数/百分比"两套单位 ✓ 所见即所得 ✓） |
| **取值范围** | **−50%（至恶）～ +50%（至善）** ✓ |
| **成长上限（新版）** | **初始上下限为 0** ✓ —— 之后**每过一个游戏日 +2%** ✓，**最高到 50% 为止** ✓（约第 25 天满格 ✓）<br>⚠ 也就是说：**刚进游戏的玩家无法累积善恶** ✓，随着世界天数增长，才逐步解锁更大的善恶空间 ✓ |
| **三条乘区** | ① **受到的伤害** ×(1 − 善恶%) ✓ ② **你的攻击伤害** ×(1 − 善恶%) ✓ ③ **最大生命** ×(1 + 善恶%) ✓ |
| **一句话概括** | **恶者手狠、善者手软**：越恶输出越高、但越脆；越善越耐打、但下手越轻 ✓ |

> 📌 文案示例：
> **「你今天的选择，都会写在身上。」** —— 每一点善良都让你更坚韧，每一点恶意都让你的刀更沉。

## 六、给介绍资料用的两条补充说明

1. **善恶是可以"玩出来"的**：全部 38 条增补规则都来自**你自己的行为**（杀生、交易、耕作、作息、战斗风格……），不依赖等级或装备 ✓。
2. **善恶是有"成长过程"的**：新角色从 **0 上限**开始，**每过一个游戏日放宽 2%**，最高 50% ✓ —— 也就是说，**越长期经营的世界，你的每个选择才越有分量** ✓。
   ⚠ 老存档玩家不会因为这条新规被削分 ✓（系统会按你已有的分值自动折算起算日 ✓）。
