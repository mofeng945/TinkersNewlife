# Tinker's Newlife 1.0.1.24-hotfix2 修复日志

本版是 **1.0.1.24 的第二个热修复**（上一版为 `1.0.1.24-hotfix`）。
内容以**修复与手感**为主，没有新增世界内容。

---

## 一、兼容性 / 崩溃

### 1. 与 Iron 法术书库（irons_lib）的启动崩溃 —— 并在冲突下保住「长矛蓄力不减速」
- 两边都想改 `LocalPlayer` 里同一处"蓄力是否减速"的逻辑，注入点被抢的一方会让游戏**启动阶段崩溃**。
- 现在改成**不抢那个注入点**的实现（改乘数常量 ＋ 末尾补起跑判定）⇒ 不再冲突，
  并且**即使装了 irons_lib，长矛蓄力依然不减速**。

### 2. 龙钢三系（龙炎 / 龙霜 / 龙霆）现在严格随冰火传说存在
- 没装冰火时，材料定义、配方、熔融流体本来就有门控；本版再补上**词条效果**的门控
  ⇒ 没冰火时龙钢三系**整条不结算**（与"材料直接消失"一致），不会出现半套残留行为。

### 3. 「七咒所缚」（恶念星灵材料）时间够了却拿不起来 —— 修复
- 根因：以前用的是"本模组自计"的受咒比例（且读原版统计的门槛写错，永远读不到），
  与神秘遗物自己的记账口径不一致 ⇒ 明明够格却每 20 秒把装备收走。
- 现在：**优先采用神秘遗物自己的权威判定**（`isTheWorthyOne` / 受咒比例），
  拿不到它的 API 才回退旧逻辑。日志里若仍被收，会打一条 `[七咒]` 诊断方便排查。

## 二、体验 / 手感

### 4. 商人墨默
- **被打必定还手**：无论创造还是生存、也无论她当时有没有别的目标，被打就锁攻击者；
- **仇恨会随时间衰减**：30 秒没有再次被攻击就会放弃追击（继续打她会续期）；
- **免疫雇主伤害**：雇佣她以后，你误伤（近战/弓箭都算）**不掉血、不记仇、不还手**；
- **成交好感度 +5**（原来 +1）；
- **每天刷新商品会重 roll 整张列表**（以前容易看成"只补货"）；
- **续雇明显化**：雇佣界面显示「当前：已雇佣（剩余 N 天）」，按钮变成「续雇 N 天」，
  续雇成功有明确提示与音效。

### 5. 「心」（善恶系统）开关改成游戏规则
- 配置文件里删除，改用 `/gamerule doConscienceHeart true|false`（默认开启），值随存档保存。

### 6. 模块化魔杖的准星
- 手持模块化魔杖、且装了「动态准心」类模组时，屏幕中心**始终补画一枚原版准星** ⇒ 不再瞄不准。

### 7. 龙霜钢命中改成"被冰龙龙息冻上"
- 命中目标时沿用冰火自己的冻结状态（冻成冰雕、无法移动/攻击），不再只是粗糙的冰霜效果；
- 同时删掉了旧的「随机铺霜冻冰块」表现（已无用）。

## 三、工具提示 / 冷却

### 8. 恢复两处被误删的提示
- **龙血储罐**：悬停带该特性的匠魂工具可看到「龙血储量 X/Y mB」（Shift 展开三种龙血）；
- **驯龙杖**：恢复"保存的龙"提示（模式 / 每个槽位的龙 / 槽位计数 / 攻击加成 / Shift 提示）。

### 9. 驯龙杖冷却改成原版物品冷却
- 收/放龙后不再刷「技能冷却中，还需 N tick」，改为**热键栏那格出现原版冷却扫光**。

### 10. 日志刷屏清理（上一版已含，这里一并列出）
- 打开构筑选择界面时不再每秒刷上百条 `Tool stack constructed using non-modifiable tool`。

---

## 四、成长 / 法术等级

### 11. 「灵性以太」远程击杀也吃成长
- 远程武器击杀现在能正确归属到玩家并给对应武器加成长；
- 弓/弩的「拉弓速度 / 初速度 / 精确度」现在也能成长（以前只涨近战与耐久）。

### 12. 「奥术始源」两个问题
- **饰品（手套 / 飞剑等）上的奥术始源现在生效**（以前只扫主手/副手/护甲，饰品完全不看）；
- **等级不再被夹到 3 级**：8 级骑士坚盾现在给 **+16 级法术等级**（2 × 等级），不再只给 +6。

- 以上改动均为**编译通过 + 静态核对**，**未逐条实机验证**；请按下列重点试玩：
  1. 装 irons_lib 能正常进游戏，长矛蓄力不减速；
  2. 商人：被打必还手、30 秒后消气、误伤不掉血、每天商品换新、续雇有提示；
  3. 恶念星灵弓射杀有成长（远程三项会涨）；
  4. 只戴手套/飞剑时法术等级有加成；
  5. 龙霜钢命中变成冰雕。
