## 0. 先决定三件事（决定后面要写多少文件）

| 决定 | 选项 | 影响 |

## 2. 数据侧（3 个 JSON；自定义部件另有 2 类）

### 2.1 `data/tinkersnewlife/tinkering/tool_definitions/<tool>.json` ★核心
模块按需拼（战镰用了 6 个 ✓）：

| 模块 | 作用 | 战镰的值 |
|---|---|---|
| `tconstruct:part_stats` | 5 个部件分别取哪个部件的属性 | `broad_blade` / `small_blade` / `tough_binding` / `tough_handle`×2，`primary_part: 0` |
| `tconstruct:default_materials` | 默认材料（`random` 按 tier 随机） | tier 1 ×5 |
| `tconstruct:base_stats` | 基础数值 | 攻击 10 / 攻速 1.5 / 耐久 1000 / 挖掘 0 |
| `tconstruct:modifier_slots` | 强化槽 | `upgrades: 5` / `abilities: 2` |
| `tconstruct:multiply_stats` | 全局倍率 | 耐久 ×1.2 / 攻击 ×0.9 / 攻速 ×0.9 |
| `tconstruct:traits` | 自带特性 | `tinkersnewlife:chaos_butterfly` lv1 |

### 2.2 `data/tinkersnewlife/tinkering/station_layouts/<tool>.json` ★核心

- `input_slots[]`：**每个槽**要有 `translation_key`（`slot.tinkersnewlife.<tool>.<槽>` ✓）＋ `icon` ＋ `filter`（限定只能放哪种部件 ✓）＋ `x/y` 坐标 ✓

### 2.3 `data/tinkersnewlife/recipes/tools/building/<tool>.json`

### 2.4（仅自定义部件需要）`recipes/tools/parts/**` ＋ `smeltery/casts`/`casts` 标签
